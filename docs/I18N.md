# 拾序 Daymark — 应用内中英文切换（i18n）

**范围**：Windows 桌面壳 / Android WebView / 共享 Web UI 的**应用内**界面语言。  
**不含**：官网（`E:\CUFE\vibecoding\Daymark website`）——官网用路径 `/`·`/en/` + `daymark-language`，与应用 `cm.app_locale` **相互独立**，互不联动。

## 架构

| 路径                                | 职责                                                                                                                         |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `apps/web/src/i18n/locale.ts`       | `Locale = "zh-CN" \| "en-US"`；默认 `zh-CN`；`localStorage["cm.app_locale"]`                                                 |
| `apps/web/src/i18n/messages/*`      | 分域文案树（common/nav/app/item/course/calendar/search/capture/account/auth/conflict/sync/errors），zh/en **键集合必须一致** |
| `apps/web/src/i18n/context.tsx`     | `I18nProvider` + `useT()` / `useI18n()`；切换即时生效并写本地偏好                                                            |
| `apps/web/src/i18n/format.ts`       | `Intl` 日期/星期/月份格式化（只影响显示，不动业务时间）                                                                      |
| `apps/web/src/LanguageSwitcher.tsx` | 全局入口：桌面侧栏 `.nav-utility`；移动端账户旁 compact                                                                      |

约定：

1. 组件只用 `t("domain.key", { param })`，禁止在 JSX 里堆三元拼文案。
2. **用户数据**（事项标题、课程名、原始捕获、教师/地点…）永不翻译。
3. 枚举显示名走消息键；工程错误经 `errors.ts` / `auth/errors.ts` 映射到产品文案。
4. 非 React 工具函数用 `getMessage(readStoredLocale(), key)`。
5. `document.documentElement.lang` 与文档标题随语言更新（标题保持品牌「拾序」）。
6. 语言偏好**不进**业务同步、不写 Supabase、不建表。

## 术语（en-US）

| 中文            | 英文                   |
| --------------- | ---------------------- |
| 事项            | Task(s)                |
| 课程            | Course(s)              |
| 学期            | Semester               |
| 日程            | Calendar               |
| 课程信息        | Course info            |
| 课程安排        | Schedule               |
| 已完成 / 未完成 | Completed / Incomplete |

## 校验

- `apps/web/src/i18n/i18n.test.ts`：键对齐、插值、locale 存取、日期格式。
- 全量门控：`pnpm format:check && pnpm lint && pnpm typecheck && pnpm test`（含 web 162 项）+ `cargo check`。

## 切换入口

- **Windows**：左侧导航底部「语言」按钮（搜索下方），弹出「简体中文 / English」菜单。
- **Android**：右上账户区旁 compact 图标按钮，同一菜单；触控目标 ≥ 44px。
- 选项固定显示各自原生名称；当前语言有勾选态。
